## Functional regression work

New `backend/tests/test_integration_composition.py` exercises the **default app**
with all three adapters enabled against controlled external transports: actual
Tiger reconciliation of source/branch, exact no-change Snowflake comparison,
enabled capabilities, narration POST, signed owner-authorized MP3 delivery and
the shared child OpenAPI. This catches mount shadowing and lifecycle/wiring
regressions that separate branch tests cannot establish.

Initial combined backend run: **389 passed, 5 failed, 2 opt-in SQL skipped**.
All five failures were a substring-based Snowflake test rejecting legitimate
decimal digits `999` as invented output. Replaced that assertion with rejection
of invented fields/citations and exact parsed numeric facts against query-derived
values. The five focused cases then passed; production comparison logic was not
weakened or changed.

Initial combined core browser run: **24 passed, 2 failed**. Both cases expected
the removed neighbor strip/Focus buttons. Tests now use actual map selection,
retain 3D conversation/zoom/mobile checks, validate all neighbor choices, and
verify animated 2D building entry/exit. Proximity is checked in the recorded
active conversation, allowing citizens to walk away after ending it. The 3D
helper reads the real renderer camera and performs an ordinary mouse click;
it does not invoke application handlers or introduce production test hooks.
No design change or scenario implementation change was made to satisfy tests.
